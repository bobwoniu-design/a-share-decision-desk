# 候选工作台

入口：选股与自选 → 今日候选 / 下个交易日计划 / 历史复盘。

- 每个用户、每个计划交易日独立保存至 `selection_days`，采用版本比较及冲突重试；不修改成交账本。
- 收盘候选按交易日历关联下一交易日，只有收盘数据成功且存在已核验题材时定稿。今日没有昨日保存的名单时允许补建，但保存真实补建时间，并显式标记；不回填历史发现时间。
- 盘中仅在 09:30–11:30、13:00–15:00 追加真实抓取的候选。重复入选合并来源，冻结每种来源的首次依据；退出排名的股票仍保留。
- 页面打开且可见时按轮次运行：同步名单、优先核验选中股票、轮询另外两只，然后等待60秒。慢接口会延长轮次；这不是全池每分钟核验。每行显示自身核验时间，2分钟后失效。
- 今日页面收盘后继续打开时会尝试准备下一交易日；进入下一交易日计划也会尝试生成。浏览器关闭或隐藏时不会继续执行。这一功能没有安装系统定时任务，也不改变已有 Bark 推送配置。
- 自动盘中发现和具体股票条件核验分离。需要交易确认时，点击股票的“立即核验”，或填写价格范围、数量、文字失效条件后“保存计划并重新核验”。人工计划不改变检查结论，也不写入成交。
- 当前核验包含近一交易日收盘以来的公告和财联社快讯、当日集合竞价、市场环境、行业/题材分钟同步、原有分钟策略、计划价格。新闻采用名称/代码及风险词匹配，可能漏报和误报，匹配不代表利空已证实。旧公告可能再次出现，须核查发布时间及原文。
- 消息核验补充异常波动、合作未确定、未签署正式协议等线索，并展示来源、发布时间和识别原因。综合快讯按分项关联公司，避免其他公司的风险串入。未命中只代表筛查未发现，消息检查保持待核验，不自动判定无风险；现阶段没有人工消息审核通过入口，因此不生成整体“条件满足”，各项行情条件仍独立显示，允许保存人工计划。
- 竞价 -3% / +7%、盘中 -3% / +8% 为透明的初版观察阈值，未经过收益验证，不等同交易建议。开盘风险检查不等待20根分钟；正向信号沿用已有分钟策略及其前日行业/题材依据，新题材证据不足保持待核验。
- 文字失效条件留给人工判断；系统不自动解释文字规则、不自动下单。价格区间由用户填写，不自动推荐。
- 历史复盘展示真实保存的状态事件；下面的收盘筛选为独立的复盘计算，不能作为过去已发现信号。

部署需应用 `drizzle/0004_needy_yellowjacket.sql`。本次开发已应用本地数据库；发布到其他环境时同样需要迁移。

验证：`npm test` 覆盖来源保留、晚补标记、信号过期、风险优先、全天发现时段、真实 SQLite 的用户隔离和并发更新。接口用登录身份及同源 JSON 写入保护。
